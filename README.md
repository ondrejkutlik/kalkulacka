# kalkulacka

Simple calculator — command-line and GUI version.

## Run

Requires Python 3.

```bash
python kalkulacka.py
python kalkulacka_gui.py
```

## Notes

- CLI supports + − * / % ** and continuing from the last result
- GUI works with mouse and keyboard (digits, operators, Enter, Backspace, Esc)
